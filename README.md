# ECOVIS RKCA — React replica

React recreation of the supplied ECOVIS RKCA Website v13 artifact. The original page markup, CSS, colors, fonts, images, text, breakpoints and interaction timing have been retained. This project is local only and has not been hosted.

## Run locally

Requires Node.js 20.19+ (Node.js 22 LTS recommended) and npm.

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite. Stop with Ctrl+C.

## Build for deployment

```bash
npm run check
npm run build
npm run preview
```

Deploy the contents of `dist/` to any static host when you are ready. Netlify and Vercel configuration files are included. No server, database, environment variables or Claude account is needed. Hash URLs work directly and do not require server-side route rewrites. Relative build paths support deployment in a subdirectory.

## Folder structure

```text
public/assets/images/     Original images, extracted and deduplicated
public/assets/fonts/      Original Adamina and Inter font files
src/components/layout/    Header and footer React components
src/components/overlays/  Contact drawer and notification dialog
src/pages/                Sixteen page components
src/data/                 Editable diagnostic, product, partner and resource data
src/runtime/              Reference interaction engine and effect cleanup
src/styles/               Original stylesheet and local font declarations
src/App.jsx               Page composition and interaction lifecycle
src/main.jsx              React entry point
docs/                     Route list, asset inventory and implementation notes
scripts/                  Asset and internal-navigation validation
dist/                     Production build generated by npm run build
```

## Included pages and interactions

- Home; i to I journey with four-stage slider.
- Governance, Risk and Compliance; Investability; Scale.
- Studio AI / ACE, products carousel and typing animations.
- Company journey, leadership, five individual partner profiles.
- Quick diagnostic, 14-question governance diagnostic and investability report.
- Publications, filterable case studies and news filtered by region.
- Mobile navigation, dropdowns, contact and notification overlays.
- Session planner with goals, dates, time slots and confirmation.

## Reference behavior and integration limits

Contact forms, notification signups and session bookings are demonstrations in the original reference. Their original labels, validation, confirmation screens and placeholder notices are retained. They do not send emails, add subscribers or reserve real appointments. There is no backend connection.

The original's optional Claude-hosted AI reading and report-download controls depend on `window.claude`. As in the reference, they stay hidden when that host capability is absent. Core diagnostics, scores and on-page reports run locally. No API keys are included.

React renders real page components; there is no iframe, remote website embed or screenshot-based implementation. The original interaction code is isolated in a lifecycle adapter to preserve behavior and animation timing. It owns the dynamic content islands inside the initially mounted page components. Keep those islands effect-owned if extending the app; do not also render their children from React state.

To change text or datasets, edit the matching page in `src/pages/` or dataset in `src/data/`. The design stylesheet is preserved in its original order because later rules intentionally override earlier rules. Retain that order to preserve the design.

Images and branding are copied from the supplied reference. Font license notices are included alongside the fonts. No new permission or license for ECOVIS branding or reference content is implied.
